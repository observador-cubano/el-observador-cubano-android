Acerca de la aplicación

Esta aplicación muestra el sitio oficial de El Observador Cubano alojado en Blogger. El contenido, las imágenes y las actualizaciones provienen directamente del periódico: la app no copia ni reconstruye las publicaciones.

Navega por artículos, comparte notas y vuelve a la portada en cualquier momento. Cuando el dispositivo recupera la conexión, la aplicación retoma la navegación automáticamente.

Nota sobre las imágenes: en algunas redes (por ejemplo, dentro de Cuba sin VPN) las imágenes alojadas por Google pueden no cargarse. El texto, la navegación y las demás funciones de la aplicación siguen funcionando con normalidad.

Lectura sin conexión

Desde un artículo puedes activar el modo lectura para verlo sin distracciones y guardarlo con el botón de marcador. El artículo y sus imágenes quedan en este dispositivo para leerlos aunque no tengas Internet.

Los guardados se almacenan solo en este teléfono y puedes eliminarlos en cualquier momento.

Historial de lectura

La aplicación recuerda los artículos que abriste y el punto donde ibas, para que puedas continuar leyendo más tarde. El historial se guarda solo en este teléfono.

Puedes borrar el historial completo o quitar artículos uno por uno cuando quieras.

Actualizaciones

La aplicación consulta las versiones estables publicadas en GitHub Releases. Antes de instalar una actualización comprueba el SHA-256, el paquete, la versión y la firma digital; si algo no coincide, la descarga se descarta.

La instalación siempre la confirma Android. No se instala nada en segundo plano.

Notificaciones

Avisos de actualizaciones

Cuando se publica una versión estable más reciente, la app puede avisarte una sola vez. Puedes posponerla con «Más tarde» y no volverá a avisar para esa misma versión. En Android 13 o superior el permiso de notificaciones se solicita solo cuando hay una actualización disponible.

Las notificaciones push de artículos nuevos son un canal distinto y requieren un proyecto de Firebase y un servidor de envío; no se muestran avisos simulados.

Privacidad

La aplicación no recopila datos personales, no crea cuentas y no solicita permisos innecesarios. Solo se conecta a Internet para mostrar el periódico. Tus preferencias se guardan únicamente en este dispositivo y puedes restablecerlas cuando quieras.

Al abrir enlaces externos se aplican las políticas de privacidad del sitio correspondiente. El periódico y Blogger pueden usar cookies propias para el funcionamiento del sitio.
